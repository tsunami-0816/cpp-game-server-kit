# 06.5_契约

本目录存放第 6.5 步接口契约校验产物。本项目为纯后端 TCP/KCP + Protobuf，**无 HTTP API、无前端**，故不产出 OpenAPI `openapi.json`；通用脚本 `scripts/api_contract_validator.py`（OpenAPI 对账）不适用，改用 Protobuf 契约对账。

- `proto_game.proto`：契约快照（自 `05_代码/backend/proto/game.proto` 复制）
- `契约校验记录.md`：消息/字段/错误码/传输格式三方对账结果、偏差清单与闸门结论
- `evidence/proto_contract_check.log`：机器对账脚本输出（`scripts/proto_contract_check.py`，退出码 0 = 0 臆造消息）
