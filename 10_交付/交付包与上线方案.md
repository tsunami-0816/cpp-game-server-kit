## 2. 上线方案

> 本项目为求职作品集，无生产部署；以下为在一台新的 Ubuntu 22.04 / WSL2 环境复现交付的步骤与回滚口径。

### 2.1 部署步骤

1. **装系统依赖**
   ```bash
   sudo apt-get update
   sudo apt-get install -y g++ cmake protobuf-compiler libprotobuf-dev \
     libhiredis-dev libmysqlclient-dev libssl-dev mysql-server redis-server
   ```
2. **初始化数据库**
   ```bash
   sudo service mysql start
   mysql -uroot < 05_代码/backend/sql/schema.sql
   mysql -uroot < 05_代码/backend/sql/fix_hash.sql
   ```
   种子账号：`user1` / `user2`，口令均 `123456`（uid=1/2）。
3. **配置环境**：`cp 05_代码/backend/.env.example.template 05_代码/backend/.env`，按本机核对 MySQL/Redis host:port。
4. **编译**：`bash scripts/build.sh`，产物在 `build/bin/`。
5. **起中间件与服务**：
   ```bash
   service mysql start
   redis-server --port 6380 --bind 127.0.0.1 --daemonize yes
   bash 08_测试/qa-automation/services.sh start
   ```
6. **回归验证**：`bash 08_测试/qa-automation/run_pytest.sh -q`，预期 49 passed / 2 xfailed / 0 failed；`python3 p0_runner.py` 预期 7 passed。

### 2.2 环境变量清单（`.env`，占位模板见 `.env.example.template`）

| 变量 | 默认值 | 说明 |
|---|---|---|
| PROJECT_NAME | cpp-game-server-kit | 项目元信息 |
| MYSQL_HOST / MYSQL_PORT | 127.0.0.1 / 3306 | MySQL 连接 |
| MYSQL_DATABASE | cpp_game | 库名 |
| MYSQL_USER / MYSQL_PASSWORD | root / 空 | 开发库；生产必须改口令 |
| REDIS_HOST / REDIS_PORT | 127.0.0.1 / 6380 | Redis（避让被占用的 6379） |
| REDIS_PASSWORD | 空 | 本地绑定缓解；生产必须加密码 |
| ECHO_PORT / GATEWAY_PORT / BATTLE_PORT | 8000 / 8001 / 8002 | 三个应用端口 |

> 已知边界：当前连接参数部分仍以源码常量为准（Q-023 deferred），环境变量读取链路未全量打通。

### 2.3 数据库初始化脚本

- `sql/schema.sql`：建 `cpp_game` 库 + `users` 表（username 唯一索引）+ 两条种子。
- `sql/fix_hash.sql`：种子口令 sha256(salt+password) 哈希校正。
- 数据备份：`07_联调/evidence/reset/backup_users_20261111_022304.sql`、`backup_users_20261111_022331.sql`。

### 2.4 回滚方案

- **代码回滚**：Git 历史内 `git revert` 对应提交；编译产物 `build/`、`build-asan/` 可整体删除后 `bash scripts/build.sh` 重建。
- **数据回滚**：用 `07_联调/evidence/reset/` 下备份 sql 恢复 users 表；Redis `session:*`/`room:*` 可直接清空回到最小种子状态（不影响 MySQL 种子）。
- **服务回滚**：`bash services.sh stop` 停掉 gateway/battle/echo；中间件 MySQL/Redis 为本机共享，不随应用回滚停止。
- **配置回滚**：`.env` 由模板复制，删除后重新复制即可回到占位默认值。

## 3. 环境收尾（10.7 交付最后一步）

### 3.1 收尾原则

- 先确认命令行归属再停止进程，不按进程名盲杀（同机可能有其他项目同名进程）。
- **不动共享中间件**：MySQL 3306、Redis 6380 为本机常驻共享服务，保持运行；不删数据卷、不删 MySQL 种子数据。
- 本项目无 Docker 容器，无 `docker compose down` 动作；`docker-compose.yml.template` 仅为模板未启用。
- 关闭前确认 DB 备份与初始化脚本已在交付包内（见 §2.3），关服务不导致交付缺件。
