## ⑦ 已知边界（属预期，不算缺陷）

| 项 | 说明 |
|---|---|
| 广播 pb 裸客户端不可解 | 广播走 KCP(ikcp_send)，Python 裸 socket 只见到 KCP 段，不模拟 KCP 接收窗口/ACK；可靠重组与重传留待 step8 补客户端验证 |
| 重连 history=0 | 探测间隔 0.3s，积压帧已被 100ms 广播清出，故拉到空历史；帧历史保留最近 100 条截断；跨重启历史未持久化（Q-013） |
| 房间态在内存 | 房间/成员/帧历史未落 Redis，重启即丢；当前 MVP 单进程内存态可跑（Q-013 deferred） |
| 错误码 3001/4001/4002 未出包 | DB 内部错误、协议解析失败、包体超长当前为静默关 fd 或通用失败；留 step6.5 契约校验时补（Q-009） |
| 业务日志未接 AsyncLogger | 网关/战斗服日志仍走 std::cerr/std::cout（Q-004） |
| 无前端 / 无 HTTP / 无 Docker | 本项目纯 C++ 后端，UI 检测、OpenAPI 校验、容器化均不适用 |
